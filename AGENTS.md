## What this is

Mitch's public GitHub profile repo (`github.com/hairglasses`). A single
`README.md` that renders as the profile landing page — a portfolio summary
pointing at the public repos worth reviewing (mcpkit, the extracted
standalone Go components, the MCP servers built on mcpkit, and sanitized
public seeds like `open-ralphglasses`).

## Conventions

- Keep it to `README.md`. There is no source, no build, no tests — this is
  presentation content, not a working codebase.
- Every linked repo must actually exist and be public before it's added here.
- Don't leak workstation, account, tenant, or operational detail — this
  file is public and is often the first thing a reviewer sees.
- Prefer real, verifiable claims (contribution graph, actual repo links)
  over unverifiable prose.
